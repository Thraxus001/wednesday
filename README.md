# Wednesday AI 🎭

A human-like cognitive AI with Wednesday Addams' personality - deadpan humor, dark wit, and analytical curiosity.

## 🚀 Quick Start

```bash
# Install in development mode
pip install -e .

# Start interactive mode
wednesday --interactive

# Or use in Python
from wednesday import quick_start
wed = quick_start()
response = wed.process_input("Hello, Wednesday!")
print(response)
